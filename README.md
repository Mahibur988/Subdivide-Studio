# Subdivide Studio 🎨📐

Subdivide Studio is a Python project that visualizes geometric subdivision using the pygame library.  
It is a conversion of a C++ SFML program into Python, with added interactivity and customization.

## 🚀 Features
- Converts C++ SFML graphics logic into Python (pygame)
- Draws and subdivides shapes based on user-defined points
- Supports subdivision operations (s, d, p)
- Interactive menu options for:
  - Splitting points
  - Averaging points
- Custom color themes
- Visual rendering of geometric transformations

## 🧠 Concepts Used
- Python programming
- Pygame graphics and rendering
- Geometry and subdivision algorithms
- Event handling and user input
- Code conversion (C++ → Python)

## 🎮 Controls
- `s` → Subdivide shape  
- `d` → Different subdivision mode  
- `p` → Process points  
- Menu options allow additional operations like splitting and averaging  

## 🛠️ How It Works
1. The program takes an initial set of points
2. Points are connected to form a shape
3. Subdivision algorithms generate smoother or more complex shapes
4. The updated shape is rendered in real-time using pygame

## 🎯 Goal
This project demonstrates how graphical algorithms and data manipulation can be combined to create dynamic visualizations.
